# Panduan Penggunaan Aplikasi Pasien Bekam

## 1. Manajemen Pasien & Kunjungan
*   **Pendaftaran Pasien**: Klik tombol "Tambah Pasien" (Hijau) untuk mendaftarkan pasien baru. ID otomatis akan dibuat jika nomor HP tidak diisi.
*   **Pencarian Cepat**: Gunakan kolom pencarian di atas daftar pasien untuk mencari berdasarkan Nama atau Nomor HP.
*   **Edit & Hapus Cepat**: Klik kanan pada nama pasien di daftar untuk mengedit profil atau menghapus data pasien secara instan.
*   **Mencatat Kunjungan**: Pilih pasien, tentukan jumlah titik bekam (harga otomatis dihitung), pilih terapis, dan tambahkan catatan medis. Klik "Catat Kunjungan".
*   **Hapus Kunjungan**: Jika ada salah input, klik kanan pada baris riwayat kunjungan di tabel dan pilih "Hapus Kunjungan".

## 2. Sistem Invoice & Kustomisasi
*   **Cetak Invoice**: Setelah mencatat kunjungan, dialog invoice akan muncul. Anda bisa memilih untuk mencetak ke PDF atau hanya melihat ringkasan.
*   **Kustomisasi Klinik**: Klik kanan tombol "Pengaturan" (Kuning) untuk mengubah Nama Klinik, Tagline, dan catatan kaki (footer) pada invoice.

## 3. Manajemen Stok Alat (Inventory)
*   **Buka Dashboard Stok**: Klik tombol "Stok Alat" (Ungu).
*   **Monitor Status**: Perhatikan warna status (Hijau = Aman, Oranye = Menipis, Merah = Habis).
*   **Kelola Stok**: Pilih item, lalu gunakan tombol "Tambah Stok" saat barang baru datang atau "Gunakan Stok" setelah sesi bekam selesai.

## 4. Analitik & Laporan
*   **Lihat Laporan**: Klik tombol "Analitik" (Biru) untuk melihat statistik kunjungan, total pemasukan, dan grafik tren bulanan.
*   **Export Data**: Klik tombol "Export" untuk mengunduh seluruh data pasien dan riwayat kunjungan ke file Excel (.xlsx).
*   **Import Data**: Gunakan tombol "Import" untuk memulihkan data dari file Excel hasil export sebelumnya.

## 5. Kalender Sunnah 2026
*   **Dashboard Utama**: Perhatikan info Tanggal Sunnah Hijriah (17, 19, 21) di dashboard utama untuk mengingatkan pasien kapan waktu terbaik untuk berbekam.
