# Panduan Install & Aktivasi Lancar Dynamic Admin

## Deskripsi Singkat

**Lancar Dynamic Admin** adalah aplikasi desktop untuk membantu klinik terapi, bekam, dan herbal mengelola administrasi harian secara lokal/offline di komputer klinik.

Aplikasi ini dapat membantu mengelola:

- data pasien
- kunjungan
- layanan
- stok herbal/produk
- invoice
- retur/void
- backup
- laporan dasar

## Persyaratan Sistem

Sebelum install, pastikan komputer memenuhi kebutuhan berikut:

- Windows 10 atau Windows 11
- RAM minimal 4 GB, disarankan 8 GB
- Ruang penyimpanan minimal 1 GB
- Printer opsional untuk cetak invoice
- Koneksi internet diperlukan untuk aktivasi/verifikasi lisensi
- Setelah aktif, aplikasi dapat digunakan secara lokal/offline sesuai aturan lisensi/trial

## Cara Install

1. Download file installer/EXE dari penyedia resmi.
2. Klik kanan file installer, lalu pilih **Run as administrator** jika diperlukan.
3. Ikuti instruksi instalasi sampai selesai.
4. Setelah instalasi selesai, buka aplikasi dari shortcut Desktop atau Start Menu.
5. Jika Windows SmartScreen muncul:
   - klik **More info**
   - klik **Run anyway**
   - pastikan file benar-benar berasal dari penyedia resmi sebelum menjalankan

## Menjalankan Aplikasi Pertama Kali

Saat aplikasi pertama kali dibuka:

- aplikasi akan membuka halaman dashboard/admin
- database lokal akan dibuat otomatis jika belum ada
- data aplikasi tersimpan di komputer klinik
- jangan menghapus folder data aplikasi
- isi profil klinik terlebih dahulu agar invoice dan informasi klinik tampil sesuai kebutuhan

## Aktivasi Trial 3 Hari

Untuk menggunakan trial:

1. Buka menu **License/Aktivasi**.
2. Masukkan license key trial yang diberikan.
3. Klik **Aktivasi** atau **Verifikasi**.
4. Pastikan muncul status trial aktif.
5. Trial berlaku selama 3 hari.
6. Data yang dimasukkan saat trial tetap tersimpan dan bisa dilanjutkan setelah aktivasi berbayar.
7. Jika trial habis, beberapa fitur dapat dibatasi sampai lisensi diaktifkan.

## Aktivasi Lisensi Berbayar

Untuk aktivasi lisensi berbayar:

1. Hubungi admin/support untuk mendapatkan license key.
2. Buka menu **License/Aktivasi**.
3. Masukkan license key yang diberikan.
4. Klik **Aktivasi**.
5. Pastikan status lisensi berubah menjadi aktif.
6. Simpan license key di tempat aman.

## Backup Data

Backup penting dilakukan rutin agar data klinik lebih aman.

Cara membuat backup:

1. Buka menu **Backup/Restore**.
2. Klik **Buat Backup**.
3. Simpan file backup di tempat aman, misalnya flashdisk atau cloud drive pribadi.
4. Lakukan backup sebelum update aplikasi.
5. Jika melakukan restore, aplikasi dapat meminta reload/restart agar data terbaru terbaca.

Disarankan membuat backup secara berkala, terutama setelah banyak input data pasien, transaksi, atau stok.

## Lokasi Data dan Keamanan

Hal penting tentang data:

- data tersimpan lokal di komputer pengguna

- jangan hapus folder data aplikasi
- lakukan backup rutin

Jika ingin pindah komputer, lakukan backup terlebih dahulu lalu hubungi support agar proses pemindahan lebih aman.

## Kendala Umum

### Aplikasi tidak bisa dibuka

- Coba jalankan aplikasi sebagai administrator.
- Restart komputer, lalu buka ulang aplikasi.
- Pastikan file aplikasi tidak dipindahkan atau dihapus sebagian.

### Windows SmartScreen muncul

- Klik **More info**.
- Klik **Run anyway**.
- Pastikan file berasal dari penyedia resmi.

### License gagal aktif

- Pastikan license key diketik dengan benar.
- Pastikan komputer terhubung ke internet saat aktivasi/verifikasi.
- Hubungi support jika pesan error tetap muncul.

### Internet tidak tersedia saat aktivasi

- Sambungkan komputer ke internet terlebih dahulu.
- Setelah aktivasi berhasil, aplikasi dapat digunakan secara lokal/offline sesuai aturan lisensi/trial.

### Invoice PDF tidak terbuka

- Pastikan aplikasi pembaca PDF tersedia di komputer.
- Coba buka ulang invoice dari aplikasi.
- Jika file tetap tidak terbuka, hubungi support dengan screenshot error.

### Printer tidak muncul

- Pastikan printer sudah terpasang di Windows.
- Coba print dokumen lain dari komputer yang sama.
- Jika perlu, buka PDF invoice lalu cetak manual dari aplikasi PDF viewer.

### Data tidak muncul setelah restore

- Restart aplikasi setelah restore.
- Pastikan file backup yang dipilih benar.
- Hubungi support jika data tetap tidak tampil.

### Trial habis

- Hubungi admin/support untuk aktivasi lisensi berbayar.
- Data trial tetap tersimpan di komputer dan dapat dilanjutkan setelah lisensi aktif.

### Lupa backup

- Cek apakah masih ada file backup sebelumnya di folder backup aplikasi.
- Jika tidak ada backup, data yang hilang mungkin tidak bisa dikembalikan.
- Biasakan membuat backup rutin dan menyimpannya di tempat terpisah.
