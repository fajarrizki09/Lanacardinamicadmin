# 🏥 Aplikasi Pasien Bekam - Versi Optimasi

Aplikasi desktop untuk manajemen data pasien bekam dengan fitur lengkap.

## ✨ Fitur Utama

### 🆕 Fitur Baru (Hasil Optimasi)
- ✅ **Data Pasien Lengkap**: Tambah field alamat dan jenis kelamin
- ✅ **Manajemen Terapis**: CRUD terapis dengan spesialisasi
- ✅ **Auto-Filter Terapis**: Filter otomatis berdasarkan jenis kelamin pasien
- ✅ **Sistem Diskon Dinamis**: Konfigurasi diskon melalui pengaturan (tidak hardcoded)
- ✅ **Tracking Terapis**: Setiap kunjungan tercatat dengan terapis yang menangani

### 📋 Fitur Existing
- Manajemen data pasien (CRUD)
- Pencatatan kunjungan dengan harga
- Riwayat kunjungan per pasien
- Analitik kunjungan dan pemasukan dengan grafik
- Export/Import data (JSON dan Excel)
- Search dan filter pasien

## 🚀 Cara Menjalankan

### Persyaratan Sistem
- Python 3.11+
- Display server (X11/Wayland) untuk GUI
- Linux/Windows/MacOS

### Instalasi Dependencies

```bash
pip install -r requirements.txt
```

Dependencies yang diperlukan:
- **PySide6** (Qt 6 framework untuk GUI - modern dan future-proof)
- **matplotlib** (untuk grafik analitik)
- **SQLAlchemy** (ORM database)

### Menjalankan Aplikasi

```bash
python main.py
```

## 🗄️ Database Schema

### Tabel `patients`
- `id`: Integer (Primary Key)
- `name`: String (Nama pasien)
- `phone`: String (Nomor HP)
- `address`: String (Alamat lengkap) **[BARU]**
- `gender`: String (Jenis kelamin: Laki-laki/Perempuan) **[BARU]**

### Tabel `therapists` **[BARU]**
- `id`: Integer (Primary Key)
- `name`: String (Nama terapis)
- `gender`: String (Jenis kelamin: Laki-laki/Perempuan)
- `specialization`: String (Spesialisasi)
- `is_active`: Boolean (Status aktif)

### Tabel `visits`
- `id`: Integer (Primary Key)
- `patient_id`: Integer (Foreign Key ke patients)
- `therapist_id`: Integer (Foreign Key ke therapists) **[BARU]**
- `date`: DateTime (Tanggal kunjungan)
- `price`: Numeric (Harga setelah diskon)
- `discount_applied`: Boolean (Status diskon diterapkan)

## ⚙️ Pengaturan

Pengaturan disimpan di file `settings.json`:

```json
{
    "base_price": 100000,
    "discount_percentage": 50,
    "min_visits_for_discount": 5
}
```

### Mengubah Pengaturan
1. Klik tombol **"Pengaturan"** di aplikasi
2. Ubah nilai yang diinginkan:
   - **Harga Dasar**: Harga default untuk kunjungan
   - **Persentase Diskon**: Diskon yang diberikan (0-100%)
   - **Minimum Kunjungan**: Jumlah kunjungan minimal untuk dapat diskon
3. Klik **"Simpan"**

## 👨‍⚕️ Manajemen Terapis

1. Klik tombol **"Kelola Terapis"**
2. Tambah terapis baru dengan:
   - Nama terapis
   - Jenis kelamin
   - Spesialisasi (opsional)
3. Terapis akan otomatis difilter berdasarkan jenis kelamin pasien saat catat kunjungan

## 📊 Fitur Auto-Filter Terapis

Ketika Anda memilih pasien untuk mencatat kunjungan:
- Dropdown terapis akan otomatis menampilkan hanya terapis dengan jenis kelamin yang sama dengan pasien
- Ini memastikan kenyamanan pasien dan sesuai dengan aturan bekam

## 🎯 Workflow Penggunaan

### Menambah Pasien Baru
1. Isi form di bagian "Tambah Pasien":
   - Nama
   - Nomor HP
   - Jenis Kelamin (dropdown)
   - Alamat
2. Klik tombol **"Tambah Pasien"**

### Mencatat Kunjungan
1. Pilih pasien dari daftar
2. Pilih terapis (otomatis filtered berdasarkan gender pasien)
3. Masukkan harga (atau gunakan harga default dari pengaturan)
4. Klik **"Catat Kunjungan"**
5. Sistem akan otomatis menerapkan diskon jika pasien sudah mencapai minimum kunjungan

### Edit Data Pasien
1. Pilih pasien dari daftar
2. Klik tombol **"Edit"**
3. Ubah data yang diperlukan
4. Hapus riwayat kunjungan jika perlu (klik kanan pada tabel)
5. Klik **"Simpan"**

## 🔧 Troubleshooting

### Import Error
Jika mendapat error saat import modules, jalankan:
```bash
python test_imports.py
```

### Display Error
Jika mendapat error `cannot connect to X server`:
- Pastikan Anda memiliki display server (X11)
- Di Linux, pastikan DISPLAY environment variable sudah di-set
- Di Windows/Mac, pastikan menjalankan dari terminal dengan GUI support

### Database Error
Jika database error:
- Hapus file `data.db` dan restart aplikasi
- Database akan otomatis dibuat ulang
